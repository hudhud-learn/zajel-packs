# zajel-packs

Audio packs for **Zajel** («زاجل», graded German and English stories), an app by Ahmad Yaghi.

This repository holds **no code** and no keys. Its releases hold one ZIP per language and level (`de-A1.zip` … `en-B2.zip`, stored/uncompressed, entries `<pack>/<story>.<kind>.m4a`) plus `index.json` (bytes and file count per pack). The app downloads them only when the learner asks.
